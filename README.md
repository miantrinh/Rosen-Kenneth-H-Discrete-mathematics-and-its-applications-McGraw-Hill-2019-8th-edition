# 📖 Discrete Mathematics: Notes, Solutions & Essays

Welcome! This is my personal space for sharing selected study notes, exercise solutions, and English writing essays based on "Discrete Mathematics and Its Applications" (8th Edition) by Kenneth H. Rosen.

I created this repository to sharpen my Computer Science foundations, practice technical English, and connect with the learning community.

---

## 📂 What's Inside?

- **[📝 Notes]**: Conceptual summaries and key takeaways.
- **[💡 Solutions]**: My own-developed solutions for selected interesting/challenging exercises.
- **[✍️ Writing Projects]**: Essays for end of chapters' writing projects.
